    Gwen Stefani - Cool
    Huge thanks to NiNEPiECES for sharing the original SD ProRes master.
    This version is my personal restoration/edit based on that source. I only did selective cleanup and cropping; the original source credit goes to NiNEPiECES.
    Source: originally shared by NiNEPiECES:
    https://sharemania.us/threads/gwen-stefani-cool.300616/

    Original source info:
    720x576 PAL, 25 fps, ProRes 422 HQ, 4:2:2, PCM audio.

    My edit / remaster:
    - Trimmed the beginning and ending black/fade sections.
    - Cropped inactive borders to the active picture area.
    - Manually inspected the full video frame by frame.
    - Applied QTGMC only to selected problem sections with visible combing / interlaced-like jagged edges.
    - Clean sections were left untouched as much as possible to preserve original detail.
    - No global AI filtering, no heavy denoise, no color regrade.
    - Exported to ProRes 422 HQ 10-bit 4:2:2 as an intermediate master.

    This is not a full-frame QTGMC pass. I used selective trims only, because full-video processing noticeably softened clean frames and fine details such as hair.
