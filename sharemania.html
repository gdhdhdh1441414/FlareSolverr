    If you don't mind converting the file to mkv, then the easiest way is using MKVToolNix. Then you can keep it that way or use LosslessCut to convert it back to mov, mp4 or any other filetype. (btw, remember to edit the audio file and sync it with the video before adding it to the file; otherwise it will be out of sync. You can use Audacity, Adobe Audition, AVConverter, etc., for this.).
