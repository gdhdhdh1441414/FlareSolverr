    AURORA - 2025-08-22 Rock en Seine, Paris, France (new VOD 1080p CFR + remastered audio)

    AURORA

    https://www.france.tv/spectacles-et...7-aurora-en-concert-a-rock-en-seine-2025.html

    The artifacted stereo livestream audio may have been rescued by france.tv by using Jusper Lee's Apollo project or code evolved from that project. It's not perfect to an audiophile, but is a massive improvement over the original. Note france.tv served dual mono for quite some time (possibly a safety backup from the soundboard). There's various discussions about the mistake on Reddit and elsewhere.

    Multiple folks did stream captures of the new VOD and none were perfect. The stream server appears to misconfigured and is outputing CFR video and tagging it as VFR. I (HAF) and others watched the version posted here and audio-video sync looks fine and appears to be CFR.

    Test for VFR vs. CFR:
    ffmpeg -i "AURORA - 2025-08-22 Rock en Seine, Paris, France (new VOD 1080p CFR + remastered audio).mkv" -vf vfrdet -f null NUL

    "If VFR:0.000000: It is a pure CFR video. None of the frames have varying durations."

    The last line of the actual test confirmed this is a pure CFR video, despite france.tv's server issue:
    "[Parsed_vfrdet_0 @ 0000000002b39b80] VFR:0.000000 (0/92467)"

    The video posted here is Fractal-Infinity's stream capture demuxed and remuxed by HugeAuroraFan with the legacy mkvextract 9.60 and mkvmerge 9.60 that is able to tag it as CFR (don't ask me if this is a bug or feature, I don't know and don't care as the 9.60 video looks, sounds, and tests fine).
